Semiconductor Devices & Quantum Physics: An Interactive Knowledge Directory

Semiconductor device physics is best navigated as a causal network rather than a list of components: materials define states, fields reshape barriers, transport produces terminal response, and internal state variables create memory or functionality. This directory provides several entrances into that network while preserving a clear route back to first principles.

Use search when you know a term, maturity filters when you want to separate foundations from research frontiers, or a learning-path preset when you want a coherent sequence. Every card opens a bilingual Knowledge Note; English is the default language throughout the collection.

How the directory is organized

  • Foundation nodes establish models and conserved quantities.
  • Engineering nodes describe established device mechanisms and system constraints.
  • Prototype nodes have convincing device demonstrations but unresolved integration challenges.
  • Frontier nodes are active research platforms whose technological role is still open.

可翻转极化能够存在于原子级薄晶体；滑移铁电中，极化来自堆叠相关的层间电荷转移，并随层间平移而反转。

打开知识节点 ↗
2D Ferroics原型
二维磁性与自旋过滤

磁各向异性和自旋轨道耦合可在原子级薄磁体中稳定有序，vdW 界面则提供洁净的自旋过滤和邻近交换。

打开知识节点 ↗
2D Ferroics前沿
二维超导与约瑟夫森物理

二维超导体结合强相位涨落、自旋轨道耦合与可栅控载流子密度；邻近效应还能把配对关联引入石墨烯或 TMD 沟道。

打开知识节点 ↗
Steep-Slope Devices基础
亚阈值摆幅与热力学极限

传统 MOSFET 通过静电移动势垒并采样热展宽的费米分布，因此在理想准静态条件下出现室温约 60 mV/dec 的下限。

打开知识节点 ↗
Steep-Slope Devices工程
新兴陡峭亚阈值晶体管

陡峭亚阈值器件通过改变注入统计、引入内部电压增益或重塑源态密度来降低开关电压。

打开知识节点 ↗
Steep-Slope Devices原型
隧穿场效应晶体管

TFET 栅极控制源区价带态与沟道导带态的空间重叠，从而开关带间隧穿。

打开知识节点 ↗
Steep-Slope Devices原型
二维、异质结与层间 TFET

原子级薄沟道增强栅控，II 型或破缺带隙 vdW 异质结缩短隧穿距离，并允许双栅独立调节能带对准。

打开知识节点 ↗
Steep-Slope Devices原型
负电容场效应晶体管

NCFET 在栅堆栈中加入铁电响应，使栅压变化可能转化为更大的半导体表面势变化。

打开知识节点 ↗
Steep-Slope Devices前沿
冷源场效应晶体管

冷源 FET 借助快速下降的源态密度或能量选择异质结抑制注入载流子的高能尾部。

打开知识节点 ↗
Steep-Slope Devices工程
陡峭亚阈值器件的基准比较

可信比较必须在相同工作点和面积尺度下同时考虑电流、斜率、电容、电压、延迟、能量、温度和滞回。

打开知识节点 ↗
Memory Physics工程
先进非易失存储器物理

非易失存储器的差别在于写入时跨越能垒、保持时被困住的状态变量：电荷、极化、原子构型、物相或磁化。

打开知识节点 ↗
Memory Physics工程
浮栅 MOS 存储器

被介质包围的浮置导体保存电子电荷，并通过电容分压改变晶体管阈值。

打开知识节点 ↗
Memory Physics工程
Flash 注入、编程与擦除物理

Flash 通过沟道热电子注入、Fowler–Nordheim 隧穿等高场输运改变存储电荷，再用低偏压读取阈值漂移。

打开知识节点 ↗
Memory Physics工程
电荷俘获型 Flash 与三维 NAND

电荷俘获单元把载流子保存在离散介质陷阱中，而非连续浮栅；三维 NAND 则通过垂直堆叠替代横向光刻缩放。

打开知识节点 ↗
Memory Physics原型
铁电场效应晶体管存储器

FeFET 在栅堆栈中保存剩余极化，极化电荷移动沟道阈值，并可通过电导进行非破坏读取。

打开知识节点 ↗
Memory Physics前沿
滑移铁电存储器件

在 vdW 双层中，电驱动的相对平移改变堆叠顺序并翻转面外偶极，从而形成结构极化存储态。

打开知识节点 ↗
Memristive Devices工程
忆阻系统与阻变物理

忆阻系统的电导由具有自身动力学的内部状态变量控制；物理实现包括离子氧化还原、物相、铁电和自旋构型。

打开知识节点 ↗
Memristive Devices工程
阻变存储器与导电细丝动力学

RRAM 通过重新分布离子和缺陷改变电阻，常表现为纳米金属细丝或富氧空位导电通道的形成与断裂。

打开知识节点 ↗
Memory Physics工程
相变存储器

PCM 利用受控焦耳热脉冲产生的非晶态与晶态电阻差保存信息。

打开知识节点 ↗
Memory Physics工程
磁阻随机存储器

MRAM 保存磁层相对磁化构型，并通过隧穿磁阻读取。

打开知识节点 ↗
Memory Physics工程
存储器可靠性、变异与缩放

保持、耐久、读写干扰、随机变异及热稳定性都是能量景观与写入应力耦合产生的结果。

打开知识节点 ↗
Neuromorphic Hardware原型
功能与神经形态器件

功能器件利用内部动力学、非易失性、光响应或随机性，使单个物理元件承担存储、传感或计算，而非只做二值开关。

打开知识节点 ↗
Neuromorphic Hardware工程
交叉阵列、选通器与潜通路

交叉阵列把电导单元放在行列交点，但若无非线性器件或访问晶体管隔离，未选路径会产生寄生电流。

打开知识节点 ↗
Neuromorphic Hardware原型
存内计算

存内计算在数据存储位置直接运算，常利用交叉阵列中的欧姆电导乘法和基尔霍夫电流求和。

打开知识节点 ↗
Neuromorphic Hardware原型
人工突触与神经形态动力学

物理突触把脉冲历史映射为电导，动态忆阻器还可利用弛豫、阈值与易失性模拟长短时可塑性或神经元动力学。

打开知识节点 ↗
Neuromorphic Hardware前沿
光电存储、光忆阻与可重构器件

把光生载流子与陷阱电荷、离子、极化或物相耦合，可使器件电导记住光照并融合感知、存储与处理。

打开知识节点 ↗
Quantum Devices原型
二维量子器件

二维材料使每个载流子都强烈感受到栅极、界面和光场，从而能在器件中组装和调控量子态，而不只由体化学成分决定。

打开知识节点 ↗
Quantum Devices原型
石墨烯电子光学器件

弹道狄拉克载流子在栅定义 p–n 界面折射，并可在相干长度和平均自由程超过器件尺寸时实现准直和聚焦。

打开知识节点 ↗
Quantum Devices原型
共振与层间隧穿器件

独立二维电极和势垒产生能谱与动量选择电流，栅极调控能级对准而不只是势垒高度。

打开知识节点 ↗
Quantum Devices原型
自旋与谷器件

自旋与谷器件借助光学手性、磁邻近、自旋轨道场或贝里曲率横向运动来产生、操纵并检测内部量子标记。

打开知识节点 ↗
Quantum Devices原型
二维磁隧道结

二维磁体、半导体和绝缘体的原子级锐利堆叠可形成由磁构型和栅极控制的自旋依赖隧穿或自旋过滤势垒。

打开知识节点 ↗
Quantum Devices前沿
激子与单光子器件

缺陷、应变势或莫尔晶格中的局域激子可逐次发射单光子，层间激子则提供电可调偶极和输运。

打开知识节点 ↗
Quantum Devices前沿
石墨烯与范德华约瑟夫森器件

超导电极在二维弱连接中诱导配对关联，栅极可调载流子密度、透射率和电流–相位关系。

打开知识节点 ↗
Quantum Devices前沿
量子点、自旋–谷量子比特与拓扑候选器件

静电限域使二维电子态离散化，自旋、谷、层或宇称可编码量子信息，并与栅极、谐振腔或超导体耦合。

打开知识节点 ↗
Electron Emission原型
冷阴极与二维电子发射器

冷阴极无需热电子加热即可向真空发射电子，通常依靠纳米边缘或尖端处的强场发射。
