Physical Picture

Nonvolatile memories differ by the state variable that crosses an energy barrier during write and remains trapped during retention: charge, polarization, atomic configuration, phase or magnetization. The useful state variables and conserved quantities must be identified before selecting a transport model. In a real device the intrinsic material response is coupled self-consistently to electrostatics, contacts, disorder and the external circuit.

Deep Derivation and Physical Interpretation

Memory as a metastable state variable

A nonvolatile cell stores information in an internal coordinate \(x\): charge, polarization, ion configuration, phase fraction or magnetization. Retention requires two or more metastable minima separated by barrier \(E_b\). Thermal escape follows

\[\tau_{ret}\approx\tau_0\exp(E_b/k_BT).\]

Writing lowers or tilts this barrier; reading must couple to \(x\) without appreciably moving it. This creates the universal write–retention–disturb triangle.

State equation and readout

The compact structure is

\[\dot x=F(x,V,T),\qquad I=G(x,V,T)V.\]

Different memory families differ in the physical meaning and spatial dimensionality of \(x\). A single lumped variable may fail when domains, filaments or crystallization fronts evolve spatially.

Meaningful comparison

Compare write energy, latency, retention at specified temperature, endurance under verified state criteria, read margin, cell area and peripheral overhead. Extrapolated ten-year retention needs a validated acceleration law; a resistance window measured immediately after programming is not nonvolatility.

Minimal Model

\[Γ_write≈Γ0 exp[-ΔE_write/kT], retention requires Γ_hold≪Γ_write\]

This expression is a compact organizing relation, not a universal fitting law. Its assumptions, dimensionality and boundary conditions must be checked before quantitative use.

Device Consequences

This hub compares floating-gate flash, charge-trap flash, FeFET, RRAM, PCM and MRAM using the same physical metrics.

The correct comparison therefore follows the causal chain

\[\text{material and geometry}\rightarrow\text{states and barriers}\rightarrow\text{transport or switching}\rightarrow\text{terminal response}.\]

Limits and Diagnostic Tests

No technology maximizes speed, density, endurance, retention, analogue linearity and process compatibility simultaneously. A credible experiment should report geometry, temperature, bias protocol, contact configuration and device-to-device statistics whenever they can change the interpretation.

物理图像

非易失存储器的差别在于写入时跨越能垒、保持时被困住的状态变量：电荷、极化、原子构型、物相或磁化。 建模前必须先确定有效状态变量和守恒量。真实器件中的本征材料响应还会与静电势、接触、无序及外部电路自洽耦合。

深入推导与物理解释

存储就是亚稳内部状态变量

非易失单元把信息保存在内部坐标 \(x\) 中：电荷、极化、离子构型、相分数或磁化。保持需要两个或更多亚稳极小值，其间能垒为 \(E_b\)。热逃逸满足

\[\tau_{ret}\approx\tau_0\exp(E_b/k_BT).\]

写入通过降低或倾斜能垒改变状态；读出必须耦合到 \(x\) 却尽量不移动它，形成普遍的“写入—保持—扰动”三角。

状态方程与读出

紧凑结构为

\[\dot x=F(x,V,T),\qquad I=G(x,V,T)V.\]

不同存储家族的区别在于 \(x\) 的物理含义及空间维度。若畴、导电细丝或晶化前沿发生空间演化，单一集总变量就会失效。

有意义的比较

应比较写能、延迟、指定温度下保持、按明确状态判据测得的耐久、读裕量、单元面积与外围开销。十年保持外推需要经验证的加速律；编程后立即测到电阻窗口并不等于非易失。

最小模型

\[Γ_write≈Γ0 exp[-ΔE_write/kT], retention requires Γ_hold≪Γ_write\]

这个式子用于组织物理关系，而不是在任何条件下都成立的拟合公式。定量使用前必须检查其近似、维度和边界条件。

器件意义

本节点用统一物理指标比较浮栅、俘获型 Flash、FeFET、RRAM、PCM 和 MRAM。

合理的分析顺序是

\[\text{材料与几何}\rightarrow\text{状态与势垒}\rightarrow\text{输运或翻转}\rightarrow\text{端口响应}.\]

限制与判据

不存在同时最大化速度、密度、耐久、保持、模拟线性和工艺兼容性的存储技术。 当几何、温度、偏压流程、接触方式或器件间统计会影响结论时，可信实验必须完整报告这些条件。
