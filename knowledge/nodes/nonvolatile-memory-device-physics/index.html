Device Physics of Nonvolatile Memory非易失存储器的器件物理

Flash and EEPROM operation from floating-gate-induced threshold shifts, including program, erase, read, retention, and endurance trade-offs.从浮栅电荷改变MOSFET阈值出发，理解Flash/EEPROM的写入、擦除、读取、保持与耐久性权衡。

Read in阅读语言

Core idea: A floating-gate memory traps charge on an electrically isolated node, shifting a MOSFET’s threshold for long periods. Programming and erasing require carriers to cross a barrier, while retention requires the same crossing probability to remain extremely small.

Figure 1 | The insulated floating gate changes the effective control-gate voltage seen by the channel. Cyferz et al., CC BY-SA 4.0; source.

Threshold Shift Stores Information

With floating-gate charge \(Q_{FG}\),

\[\Delta V_T\approx-\frac{Q_{FG}}{C_{eff}},\]

where \(C_{eff}\) belongs to the capacitance network coupling the floating gate to control gate, channel, source, drain, and body. Reading only tests channel conduction at a selected gate voltage; it need not remove stored charge.

Program and Erase

Hot-electron injection uses a high drain field to give a small fraction of channel electrons enough energy to cross the Si/SiO\(_2\) barrier. It is fast but power-hungry and spatially nonuniform.

Fowler–Nordheim tunneling uses a strong oxide field to triangularize the barrier:

\[J_{FN}\propto E_{ox}^2\exp\left(-\frac{B}{E_{ox}}\right).\]

Changing field direction allows programming or erasing. Very thin dielectrics can enter direct tunneling.

Retention, Endurance, and Read Window

  • Retention demands negligible tunneling and trap-assisted leakage.
  • Repeated high-field cycling creates oxide and interface traps, degrading endurance.
  • Read and neighbor-cell operations must not disturb the stored state.
  • MLC/TLC/QLC pack more threshold windows into one cell, increasing density while shrinking noise margin.

Fast writing and decade-long retention ask for opposite tunneling probabilities, balanced through pulse algorithms, barrier design, voltage, and error correction.

Beyond Floating Gates

Charge-trap memories localize charge in dielectric defects; FeFETs store ferroelectric polarization; RRAM stores conductive-filament or valence states; PCM stores amorphous/crystalline phase; MRAM stores magnetic configuration. They can be compared using the same questions: state variable, write barrier, read disturb, retention, endurance, and variability.

1. 阈值漂移就是信息

浮栅存储电荷 \(Q_{FG}\) 后，控制栅到沟道的电势耦合发生改变。第一近似下

\[\Delta V_T\approx-\frac{Q_{FG}}{C_{eff}},\]

其中 \(C_{eff}\) 由浮栅与控制栅、沟道、源漏及衬底的电容网络决定。读取时只需在选定栅压下判断沟道是否导通，无需移走存储电荷。

2. 写入与擦除

热电子注入

漏端高场使沟道电子获得能量，少部分跨越 Si/SiO\(_2\) 势垒进入浮栅。它速度快，但耗电较大且空间分布不均。

Fowler–Nordheim隧穿

强氧化层电场使势垒近似三角形，电子隧穿电流常呈

\[J_{FN}\propto E_{ox}^2\exp\left(-\frac{B}{E_{ox}}\right).\]

它可用于写入或擦除，方向由电场决定。极薄介质中还可能转为直接隧穿。

3. 保持、耐久与读取窗口

  • 保持性：浮栅电荷不应经隧穿、陷阱辅助通道或缺陷泄漏；
  • 耐久性：反复高场注入会生成氧化层和界面陷阱，移动阈值并增加漏电；
  • 读取干扰：反复读取或邻近单元操作不应改变存储态；
  • 多级存储：MLC/TLC/QLC 把多个阈值窗口塞进一个单元，提高密度但缩小噪声裕量。

写入速度需要高穿隧概率，十年保持需要低穿隧概率；工程上通过脉冲、势垒厚度、电压和纠错码共同平衡。

4. 从浮栅到其他非易失机制

  • 电荷俘获存储器把电荷保存在离散介质陷阱中，降低单一泄漏通道的灾难性影响；
  • FeFET 用铁电极化移动阈值，但受退极化、陷阱和循环疲劳影响；
  • RRAM 用导电细丝/价态变化改变电阻；
  • PCM 用非晶/晶态电阻差保存信息；
  • MRAM 用磁隧道结的磁化构型保存信息。

它们不都属于传统施敏课程的 MOS 主线，但可以用同一分析模板比较：状态变量、写入能垒、读取扰动、保持、耐久和变异性。
