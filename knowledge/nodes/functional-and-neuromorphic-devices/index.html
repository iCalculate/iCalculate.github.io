Physical Picture

Functional devices exploit internal dynamics, nonvolatility, optical response or stochasticity so that one physical element performs memory, sensing or computation rather than only binary switching. The useful state variables and conserved quantities must be identified before selecting a transport model. In a real device the intrinsic material response is coupled self-consistently to electrostatics, contacts, disorder and the external circuit.

Deep Derivation and Physical Interpretation

Computation in a physical state space

A functional device is defined by its internal dynamics, not by a material label. With state vector \(\mathbf x\), input \(\mathbf u\) and measured output \(\mathbf y\),

\[\dot{\mathbf x}=\mathbf F(\mathbf x,\mathbf u)+\boldsymbol\xi(t), \qquad \mathbf y=\mathbf G(\mathbf x,\mathbf u).\]

Nonvolatility corresponds to multiple stable fixed points; fading memory to relaxation times comparable with the input sequence; stochastic computing to controlled noise \(\boldsymbol\xi\). The same physical volatility that is a failure for storage can be useful for reservoir computing or neuron leakage.

Matching time and energy scales

Useful dynamics require \(\tau_{device}\) to match the algorithmic timestep. If much shorter, state vanishes before readout; if much longer, training becomes slow. End-to-end energy includes write pulses, sensing, conversion, routing and refresh:

\[E_{system}=E_{cell}+E_{drivers}+E_{ADC/DAC}+E_{data}.\]

Evidence of function

A device demonstration should compare against a baseline using identical precision and workload. Material-level hysteresis is not yet computation. Report state dimensionality, update law, noise, drift, calibration frequency, peripheral area and accuracy under held-out data.

Minimal Model

\[Device state x(t) becomes part of the computation\]

This expression is a compact organizing relation, not a universal fitting law. Its assumptions, dimensionality and boundary conditions must be checked before quantitative use.

Device Consequences

This hub connects arrays, selectors, compute-in-memory, artificial synapses, photomemristors and reconfigurable logic–memory devices.

The correct comparison therefore follows the causal chain

\[\text{material and geometry}\rightarrow\text{states and barriers}\rightarrow\text{transport or switching}\rightarrow\text{terminal response}.\]

Limits and Diagnostic Tests

Device novelty does not automatically translate to system benefit; peripheral circuits, calibration and data movement dominate many demonstrations. A credible experiment should report geometry, temperature, bias protocol, contact configuration and device-to-device statistics whenever they can change the interpretation.

深入推导与物理解释

在物理状态空间中计算

功能器件由内部动力学而非材料标签定义。设状态向量 \(\mathbf x\)、输入 \(\mathbf u\)、输出 \(\mathbf y\)：

\[\dot{\mathbf x}=\mathbf F(\mathbf x,\mathbf u)+\boldsymbol\xi(t), \qquad \mathbf y=\mathbf G(\mathbf x,\mathbf u).\]

非易失对应多个稳定不动点；衰减记忆要求弛豫时间与输入序列相当；随机计算则利用受控噪声 \(\boldsymbol\xi\)。同一种易失性对存储是缺陷，对储备池计算或神经元漏积分却可能是功能。

匹配时间与能量尺度

器件时间常数 \(\tau_{device}\) 必须匹配算法时间步：过短则读出前消失，过长则训练缓慢。端到端能量包含单元、驱动、转换、互连和刷新：

\[E_{system}=E_{cell}+E_{drivers}+E_{ADC/DAC}+E_{data}.\]

功能证据

器件演示应在相同精度和工作负载下与基线比较。材料滞回本身还不是计算；需要报告状态维度、更新律、噪声、漂移、校准频率、外围面积以及留出数据上的准确率。

最小模型

\[Device state x(t) becomes part of the computation\]

这个式子用于组织物理关系，而不是在任何条件下都成立的拟合公式。定量使用前必须检查其近似、维度和边界条件。

器件意义

本节点连接阵列、选通器、存内计算、人工突触、光忆阻及可重构逻辑–存储器件。

合理的分析顺序是

\[\text{材料与几何}\rightarrow\text{状态与势垒}\rightarrow\text{输运或翻转}\rightarrow\text{端口响应}.\]

限制与判据

器件新颖性不会自动转化为系统收益，外围电路、校准和数据搬运常主导真实演示。 当几何、温度、偏压流程、接触方式或器件间统计会影响结论时，可信实验必须完整报告这些条件。
