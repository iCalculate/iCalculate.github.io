Physical Picture

RRAM switches resistance by redistributing ions and defects, often forming or rupturing a nanoscale metallic or oxygen-vacancy-rich conduction path. The useful state variables and conserved quantities must be identified before selecting a transport model. In a real device the intrinsic material response is coupled self-consistently to electrostatics, contacts, disorder and the external circuit.

Minimal Model

\[J_ion∝cE exp(-E_a/kT); local Joule heating couples back to motion\]

This expression is a compact organizing relation, not a universal fitting law. Its assumptions, dimensionality and boundary conditions must be checked before quantitative use.

Device Consequences

Valence-change, electrochemical-metallization and thermochemical cells provide dense two-terminal memory and analogue conductance states.

Limits and Diagnostic Tests

Atomic stochasticity produces forming variation, cycle variability, random telegraph noise and endurance failure. A credible experiment should report geometry, temperature, bias protocol, contact configuration and device-to-device statistics whenever they can change the interpretation.
